# 已弃用的反向段码版本

本目录保留 2026-10-27 用户反馈“COM7、bringup 只有 4 正常”时的旧源码、发布物和指标，用于定位与追溯。**这里的 bit 与旧交付包存在段码位序错误，不可继续用于验收。** 当前修正版以项目根目录 `release` 为准。

原理图给出的网络是 H15=A、G16=B、L13=C、G15=D、K13=E、G13=F、H14=G、J14=DOT。XDC 引脚分配本身正确，错误在于 RTL 按相反的段序编码。0–9 的物理段形测试在旧版本上 9 失败、1 通过，唯一通过的是 4，复现用户特征。旧 RTL 仿真重复使用相同错误常量，因而未发现物理契约错误。
