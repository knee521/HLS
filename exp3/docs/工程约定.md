# 实验三工程约定

本项目按执行文档固定784→32→10、50 MHz、xc7a35tfgg484-2、Vivado/HLS 2018.3。用户已授权实现全部非硬件操作，硬件下载、接线、复位、现场识别和板上性能测试由用户完成。

- Python使用独立3.12环境、模块入口`python -m package.module`、集中配置、类型标注与标准日志；GUI、CLI共享协议和预处理。
- 核心整数语义固定，不在测试集上选择量化参数。所有正式测试记录完整分母，失败不得静默丢弃。
- HLS使用C++03、固定容量、显式符号扩展及溢出证明；仿真与综合同源。生成权重带模型哈希，禁止手改。
- RTL使用单时钟、同步内部复位、明确valid/ready、默认关闭隐式网络、统一timescale；异步输入同步后使用。
- 源码、生成物、原始数据、证据、发布包分目录；修改后执行相关回归，发布前执行全部规定检查。
- 命令统一保存完整日志、退出码、耗时。预计结果、仿真结果、综合估算、实现结果、板上实测分开标注。
- 硬件关卡暂不通过不伪造完成；独立的软件关卡继续推进，并在交付清单记录依赖。

开发决策：CPU版PyTorch 2.5.1与torchvision 0.20.1，使用官方配对版本；无需CUDA。工具路径按本机实际安装记录。报告中的个人身份、心得和签名由本人填写。
